# 글쓰기 안내

이 `_obsidian` 폴더는 블로그에 올라가지 않는다 (config.yml 의 ignoreFiles).

## 새 글 만들기

1. 카테고리 폴더(예: `untitled_cs/cod`)를 우클릭 → **새 폴더**. 폴더 이름이 글 주소가 된다 → `/posts/untitled_cs/cod/폴더이름/`. 영문 소문자와 하이픈을 권장 (예: `ch2-instructions`).
2. 만든 폴더를 우클릭 → **새 노트** → 이름을 `index` 로.
3. `Ctrl+P` → **템플릿: 템플릿 삽입** (Templates: Insert template) → `글` 또는 `글 (영어 포함)`.
4. 속성 채우기
   - `title`: 글 제목
   - `description`: 카드와 검색에 나오는 한 줄 설명 (비우면 본문 앞부분)
   - `tags`: 태그 (기존 태그와 대소문자까지 똑같이: BOJ, DP …)
   - `thumbnail`: 대표 이미지 (예: `images/cover.png`, 비우면 없음)
5. 다 쓰면 `draft` 체크를 끈다 → GitHub Desktop 으로 커밋 · 푸시 → 1~2분 뒤 공개.

## 쓰는 법

- **소제목**은 `##` 부터 (`##` = 섹터, `###` = 하위 항목). 글 제목은 속성의 title 이 쓰이므로 `#` 는 쓰지 않는다.
- **이미지**는 그냥 붙여 넣기(`Ctrl+V`) 하거나 끌어다 놓는다. 글 폴더의 `images/` 에 저장되고 링크도 자동으로 들어간다. 설명은 `![여기에 설명](...)`.
- **다른 글 링크**는 `[[ ]]` 대신 `[보여줄 글자](../../boj/31095/index.md)` 형태. 링크 넣기(`Ctrl+K`)나 파일을 끌어다 놓으면 이 형태로 들어간다.
- **줄바꿈**: 엔터 한 번은 블로그에서 같은 문단으로 이어진다 (Obsidian 도 그렇게 보이도록 맞춰 둠). 문단을 나누려면 빈 줄을 둔다.
- **수식**: `$a^2$` (문장 속), `$$ … $$` (단독). Obsidian 미리보기와 블로그가 같다.
- **콜아웃**: `> [!note]`, `> [!tip] 제목`, `> [!warning]` … (접기 표시 `-` 는 블로그에서는 펼친 채로 보인다)
- **코드**: ```` ```c++ ```` 처럼 언어 이름을 붙인다. 블로그에서 줄 번호 · 복사 버튼이 붙는다.
- **영어 번역**: 한국어 본문 아래에 `{{< en >}}` … `{{< /en >}}`. 영어 소제목도 한국어와 같은 수의 `##` 로, 앵커는 `## Title {#en-title}`. 블로그에 KO/EN 스위치가 생긴다.
- **예약 발행**: `date` 를 미래 날짜로 적으면 그날 0시 5분 자동 빌드 때 공개된다.

## 주의

- 카테고리 폴더의 `_index.md` 는 카테고리 설정(이름 · 설명 · 색 · 순서) 파일이다.
- 글 폴더 없이 만든 노트도 글로 올라간다. 커밋 전에 GitHub Desktop 목록에서 모르는 파일이 없는지 본다.
- 블로그에서 미리 보려면 저장소 폴더(`E:\blogGithub\coldburgundy.github.io`)에서 `hugo server -D` 를 실행하고 http://localhost:1313/posts/ 를 연다 (`-D` 는 draft 글도 보여 줌).
